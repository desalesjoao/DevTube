DevTube - Portal de Aulas de Programação
Projeto desenvolvido como parte das atividades práticas de desenvolvimento web, utilizando CSS Grid para a estrutura principal do layout e Flexbox para o alinhamento e distribuição dos componentes internos.

Funcionalidades e Layout
O projeto simula uma plataforma moderna de streaming de aulas de programação no estilo YouTube, contendo:

Cabeçalho desenvolvido com Flexbox, contendo a logomarca, barra de pesquisa centralizada e botão de login.

Barra lateral esquerda com a listagem completa de matérias e disciplinas de programação, como HTML, CSS, JavaScript, Python, React e SQL.

Conteúdo principal organizado em uma grade de cards de aulas utilizando Flexbox com quebra de linha e espaçamento otimizado, contendo diversos itens para demonstrar o efeito de rolagem.

Barra lateral direita com o menu de navegação secundário da plataforma.

Rodapé contendo informações de direitos reservados.

Tecnologias Utilizadas
HTML5 para a estruturação semântica.

CSS3 para a estilização e reset global.

CSS Grid Layout para o posicionamento das áreas da página.

CSS Flexbox para o alinhamento dos componentes internos.

Requisitos Técnicos Atendidos
O layout ocupa exatamente toda a altura visível da tela.

Apenas os containers internos de conteúdo possuem rolagem independente, mantendo o cabeçalho e o rodapé fixos.

Estilização moderna com cores escuras, espaçamentos consistentes e efeitos de transição suave ao passar o mouse.

Totalmente textual, sem dependência de ícones externos ou imagens pesadas.
